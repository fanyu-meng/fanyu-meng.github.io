隐私政策

视频发布台（Google 应用名 autoPublish）· 更新于 2026-11-26

这是什么

视频发布台是孟凡雨为自己的个人网站搭建的工具，用来把自己的视频上传到自己的 YouTube 频道。它只服务于网站作者本人，不对外开放注册。

使用哪些 Google 数据

授权时只申请两项 YouTube 权限：上传视频（youtube.upload），以及读取频道信息（youtube.readonly），用于确认频道 ID 和已上传视频的公开状态。不读取邮件、通讯录、云端硬盘等其他数据。

数据保存在哪里

授权得到的令牌和频道 ID 以加密形式保存在作者本人的 GitHub 私有仓库的 Actions Secrets 中，只在后台发布任务里使用。原片和封面保存在同一私有仓库。本网站不设账号系统，不使用广告或第三方统计，不出售、不向任何第三方分享这些数据。

撤销授权

可以随时在 Google 账号的第三方访问管理 中撤销对本应用的授权，撤销后发布台无法再访问 YouTube 频道。

English summary

Video Studio (Google app name "autoPublish") is a personal tool used only by the site owner, Fanyu Meng, to upload the owner's own videos to the owner's own YouTube channel. It requests only the youtube.upload and youtube.readonly scopes. OAuth tokens and the channel ID are stored encrypted as GitHub Actions secrets in the owner's private repository and are never sold or shared with third parties. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.

联系
